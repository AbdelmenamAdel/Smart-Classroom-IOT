Smart Classroom IOT

Comprehensive Project Report & Documentation

1. Project Overview

Problem Statement

Traditional classroom management relies on manual monitoring of environmental factors and energy usage. Lights are often left on when not needed, and environmental conditions are not tracked, impacting comfort and focus.

Objectives

  • Real-time monitoring of environmental conditions.
  • Dual-protocol connectivity (Firebase & MQTT).
  • Automated/Remote energy-saving lighting control.
  • Live student occupancy tracking.
  • Historical data visualization via trends.

Proposed Solution

A multi-layered IoT ecosystem integrating hardware (ESP32/ESP8266), cloud synchronization (Firebase/Mosquitto), and a high-performance Flutter mobile application.

5. Firmware Implementation

The hardware logic is implemented in C++ using the Arduino framework for ESP8266. Key features include:

  • Bi-directional Counting: Sequence-based IR sensor logic.
  • Dual Cloud Sync: Simultaneous updates to Firebase and MQTT.
  • Auto/Manual Logic: Smart occupancy-based control with manual override.
